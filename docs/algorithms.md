# Sorting Algorithms Documentation

## 1. Selection Sort
  Repeatedly selects the minimum element and places it at the beginning.

## 2. Insertion Sort
  Builds the sorted array one element at a time.

## 3. Merge Sort
  Divide-and-conquer: recursively splits and merges subarrays.

## 4. Quick Sort
  Partition-based divide-and-conquer algorithm.


| Algorithm      | Best       | Avg        | Worst      | Space    | Stable |
| -------------- | ---------- | ---------- | ---------- | -------- | ------ |
| Selection Sort | O(n²)      | O(n²)      | O(n²)      | O(1)     | No     |
| Insertion Sort | O(n)       | O(n²)      | O(n²)      | O(1)     | Yes    |
| Merge Sort     | O(n log n) | O(n log n) | O(n log n) | O(n)     | Yes    |
| Quick Sort     | O(n log n) | O(n log n) | O(n²)      | O(log n) | No     |
