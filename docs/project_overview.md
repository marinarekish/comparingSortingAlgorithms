# Project Overview

This project studies the performance of four classic sorting algorithms:

- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

The goal is not to reinvent these algorithms but to:

✔ compare their performance  
✔ evaluate scalability  
✔ analyze random vs. worst-case behavior  
✔ measure execution time using a unified benchmarking engine

The benchmarking system includes:

1. JIT warmup
2. worst-case generator
3. correctness validation
4. multi-trial averaging
5. clean separation of concerns
